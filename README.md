## How to Run Locally

If you are opening this repository locally or working inside a development environment like GitHub Codespaces, you can start a local server to test the interactive panoramas:

1. Open your terminal in the root directory of the project.
2. Run the following command:
   ```bash
   python3 -m http.server 8000
